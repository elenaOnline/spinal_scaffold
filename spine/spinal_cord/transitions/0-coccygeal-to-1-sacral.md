# coccygeal → sacral : the seed becomes a want

<!-- The loosest handoff. The base is undifferentiated; promotion here is light. -->

## What moves
A seed in `coccygeal_differentiation/` is recognized as carrying a genuine *desire* and is
voiced as a new desire-spec in `sacral_unconscious/`. The seed itself remains as a record of
origin.

## Reflex conditions
- [ ] Seed `status: seed`.
- [ ] *The spark* is present and nameable (not an empty stub).
- [ ] An owner judges it carries a **want**, not merely a curiosity — i.e. it can be phrased
      as "we want X so that Y."

## On promotion
- Create a sacral spec from the desire template, with `seed:` linked back to this seed.
- Set seed `status: promoted`.
- (A seed judged not to carry a want is set `status: dropped`, not promoted.)

## Escalation
Relay to the crown **before** promoting when the seed implies a direction that conflicts
with existing desires or with the project's telos. Whether a new want belongs in the project
at all is whole-system judgment — the cord cannot read it from local frontmatter.
