# 2 · Lumbar Architecture

> *The load-bearing vertebrae. Where desire is given bones.*

The lumbar spine carries the most structural load. Here, the wants surfaced in the
[`../sacral_unconscious/`](../sacral_unconscious/) are translated into **technical
write-ups** — the architecture of features and items. This is where "what we want" becomes
"what it is and how it is built," with enough rigor to bear weight.

## What lives here

- Technical write-ups for individual features and items
- Data models, interfaces, contracts, and component boundaries
- Trade-off analyses and design decisions
- The structural truth a plan can be drawn against

## How to work here

- Each write-up should name the desire (from the sacral layer) it gives structure to.
- Be concrete about mechanism: this is the layer that prescribes *how*.
- Keep one feature/item per document where possible, so the thoracic layer can fold them
  into independent waves.
- When the structure is sound, promote it into a wave plan in
  [`../thoracic_infolding/`](../thoracic_infolding/).

If something above cannot stand, the fault is usually a missing bone here.
