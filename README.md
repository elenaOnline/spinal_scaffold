# spinal_scaffold

A conceptual development paradigm loosely inspired by *Spinal Catastrophism* by Thomas Moynihan.
Built for use with, and with the aid of, Claude Code.

Ascension up the spine acts as an idea's ontogenesis. Starting at the coccyx, the development cycle takes a nascent idea, orients it away from the ground, and forces it into a state of self-recognition and ultimately self-governance. The project acts as a spine to orient and structure the development of a program, but it is the program, not the bones, that is capable of procedural unfolding and infolding.


A project planned and governed with the **Spinal Development** paradigm.

The paradigm lives in [`spine/`](./spine/) — a self-contained column that models project
architecture on the human spine. Work enters as raw idea at the base and ascends, vertebra by
vertebra, into governed execution.

## Layout

| Path | What's there |
|------|--------------|
| [`spine/`](./spine/) | The Spinal Development column — vertebra folders, spinal cord, and governance docs |
| [`spine/.human/spinal_column.html`](./spine/.human/spinal_column.html) | The dashboard — open this to see the column at a glance |

## The column

Work ascends base-to-crown; nothing skips a vertebra:

| # | Vertebra | Folder | Function |
|---|----------|--------|----------|
| 0 | Coccygeal | `spine/coccygeal_differentiation/` | Ideation; the seedbed of future updates |
| 1 | Sacral | `spine/sacral_unconscious/` | Desire-oriented spec documents |
| 2 | Lumbar | `spine/lumbar_architecture/` | Technical write-ups for features/items |
| 3 | Thoracic | `spine/thoracic_infolding/` | Parallelized, wave-based implementation plans |
| 4 | Cervical | `spine/cervical_awareness/` | Guidelines, procedures, oversight |

Threaded through every vertebra is the `spine/spinal_cord/`, which carries movement between
levels. See [`spine/README.md`](./spine/README.md) for the full account.

## Getting started

1. Open [`spine/.human/spinal_column.html`](./spine/.human/spinal_column.html) to view the dashboard.
2. Drop your first seed in [`spine/coccygeal_differentiation/`](./spine/coccygeal_differentiation/).
